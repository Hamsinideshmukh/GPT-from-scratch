# GPT from Scratch

A from-scratch implementation of a **decoder-only Generatively Pretrained Transformer (GPT)** in PyTorch, inspired by Andrej Karpathy’s tutorial and grounded in the original Transformer paper **Attention Is All You Need (Vaswani et al., 2017)**  and the GPT-2 / GPT-3 design direction.
Note that this is implementation is a decoder-only Transformer unlike the one implemented in original paper which wasn't intended for auto-regressive language modeling use case like ours.
